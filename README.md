# 🌦️ ClarityWeather — Smart Weather App

🔗 **Live Demo:** https://gitankitakumari.github.io/weather-app/
📂 **GitHub Repo:** https://github.com/gitankitakumari/weather-app

---

A modern and interactive weather web app that provides real-time weather data, forecast, AQI, and more with a clean and responsive UI.

---

## 🚀 Features

* 🔍 Search weather by city
* 📍 Get weather using current location
* 📊 5-day forecast with chart
* 🌫️ Air Quality Index (AQI)
* 🌙 Dark / Light mode toggle
* 🌐 Multi-language support (English + Hindi)
* 🎤 Voice search support
* 🔊 Text-to-speech weather reading
* 📜 Recent search history (localStorage)
* 📱 Fully responsive UI

---

## 🛠️ Tech Stack

* HTML5
* CSS3
* JavaScript (ES6 Modules)
* OpenWeather API
* Chart.js
* Leaflet.js

---

## ⚙️ How It Works

* Weather data is fetched from OpenWeather API
* API handling is done in `api.js`
* UI updates handled in `ui.js`
* Main logic handled in `main.js`
* Local storage & utilities handled in `utils.js`

---

## 🔑 Setup Instructions

1. Clone the repository:

```
git clone https://github.com/gitankitakumari/weather-app.git
```

2. Open project folder

3. Replace API key in `api.js`:

```js
const API_KEY = "your_api_key_here";
```

4. Run project:

```
open index.html
```
